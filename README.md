# Museum Project

Коммерческий музейный сайт, реализованный как многостраничный статический проект. Каждая страница была разработана отдельно, а итоговая сборка и интеграция выполнялись уже на этапе подготовки к публикации

## О проекте

Этот проект представляет собой веб-сайт для музейной тематики с разделами:

- главная страница;
- страницы о фабриках и производстве;
- страницы событий, документов и наград;
- разделы с людьми, руководителями и мультимедиа;
- поиск по контенту;

## Что реализовано

- многостраничная структура сайта;
- адаптивная верстка;
- интерактивные элементы: слайдеры, модальные окна, фильтры, поиск;
- работа с изображениями, аудио, видео и документами;
- единая навигация по разделам проекта;

## Структура проекта

- index.html — стартовая страница с навигацией по всем разделам;
- src/pages — HTML-страницы проекта;
- src/styles — стили и SCSS-модули;
- src/scripts — JavaScript для интерактивности;
- src/assets — изображения, аудио, видео, шрифты и другие ресурсы;

## Как открыть проект

1. Откройте файл index.html в браузере
2. Для удобства можно использовать Live Server или любой другой локальный сервер

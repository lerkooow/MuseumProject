Коммерческий музейный проект

Презентационная страница проекта

Это многостраничный сайт для музея, разработанный как набор отдельных экранов и контентных страниц. Каждая страница была создана отдельно, а итоговая композиция и сборка проекта выполнялись уже на этапе подготовки к публикации.

HTML CSS / SCSS JavaScript Мультимедиа

Что входит в проект

Сайт включает главную страницу, разделы о фабриках, событиях, документах, наградах, людях, руководителях, мультимедиа и поиск по материалам

Цель проекта

Показать музейную историю через современный веб-интерфейс с акцентом на визуальное восприятие и структуру контента

Подход к разработке

Каждая страница была сделана как самостоятельный блок, а затем объединена в единый проект с общей навигацией
